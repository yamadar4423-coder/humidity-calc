# 湿度計算ツール（shitsudo-calc）

気温・相対湿度・絶対湿度（容積絶対湿度）・露点温度のうち **任意の2項目**を入力すると残り2項目を算出する、スマホ対応の現場向けWebアプリです。あわせて重量絶対湿度・比エンタルピー・湿球温度も算出し、外気と室内の状態を比較できます。

## 使い方

### 単一計算モード
1. 4項目（気温・相対湿度・絶対湿度・露点温度）のうち **ちょうど2項目**を入力
2. 「計算する」を押す → 残り2項目（オレンジ表示）＋詳細（重量絶対湿度・比エンタルピー・湿球温度）を算出
3. 結果は履歴に自動保存（青セル＝入力値）。**地点ラベル**（外気/寝室など）を任意で付与可能

### 室内外比較モード
- 外気の気温・相対湿度と室内気温を入力すると、**露点温度（水分量）を一定**に保ったまま室内の相対湿度・容積/重量絶対湿度・湿球温度を算出。
- 「外気を室内に取り込み温度だけ変えた（水分の出入りなし）」場合を想定した顕熱変化。空気線図では**水平線**で表示。
- 室内気温が外気の露点を下回る場合は**結露**を警告。

### 共通
- **温度単位切替**：℃ / ℉ / K（内部計算は常に℃、表示のみ変換）
- **空気線図（湿り空気線図）**：横軸=乾球温度 / 縦軸=重量絶対湿度。飽和線・RH等値線・計算点をプロット。

## 計算する内容

- 相対湿度・容積絶対湿度（g/m³）・露点温度
- 重量絶対湿度（g/kg(DA)）・比エンタルピー（kJ/kg(DA)）・湿球温度
- 室内外2点の比較（露点一定）

## 計算式

- 飽和水蒸気圧（Tetens/Magnus式）：`es(T) = 6.1078 × 10^(7.5T/(T+237.3))` [hPa]
- 蒸気圧→露点：`Td = 237.3L/(7.5−L)`, `L = log10(e/6.1078)`
- 容積絶対湿度：`a = 216.7 × e/(T+273.15)` [g/m³]
- 重量絶対湿度：`x = 622 × e/(P−e)` [g/kg(DA)]
- 比エンタルピー：`h = 1.006T + x(2501+1.86T)/1000` [kJ/kg(DA)]
- 湿球温度：乾湿計式 `e = es(Tw) − A·P·(T−Tw)`（A=6.62×10⁻⁴）の反復解
- **大気圧 P は標準 1013.25 hPa 固定**

## 技術メモ

- 単一HTMLファイル（HTML / CSS / JavaScript 内蔵、外部依存ゼロ）
- **完全オフライン動作**（`file://` 直開きで全機能動作）。iPhone Safari 等スマホ最適化
- 履歴は localStorage（キー `kizuna_humidity_history_v2`）。不可環境ではメモリのみにフォールバック
- 配色は `:root` の CSS 変数で管理

## 制約・注意

- 大気圧は標準大気圧固定。高地・加圧環境では誤差が生じる。
- Tetens式は −50〜60℃ 程度で実用精度。氷点下の飽和水蒸気圧は水面上の式を流用のため、氷点下ではやや低めの露点を示す。
- 計算結果は実務上の目安値です。
